# Quiz-game-project2

This is a console-based Quiz Game developed using the C programming language.
The project is designed to practice fundamental C concepts and implement basic game logic.

About the Project
-----------------
The quiz presents multiple-choice questions to the user, accepts input, and calculates the final score based on correct answers.

Features
--------
Multiple-choice questions
Score calculation
User-friendly console interaction
Input validation

Technology Used
---------------
Programming Language: C

How the Game Works
------------------
The user answers a set of questions by selecting the correct option.
Each correct answer increases the score.
The final score is displayed at the end of the quiz.
